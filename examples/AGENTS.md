# examples/AGENTS.md

本文件适用于 `examples/` 下的配置示例。

## 示例定位

- 示例是按配置类型或关键能力组织的独立参考片段，不要求共同组成可直接运行的配置闭包。
- 每份示例都应展示不可由现有示例替代的字段、结构或行为边界。
- 不要仅为补齐另一份示例的路径引用或 definition binding 新增辅助文件。

## 内容要求

- 每份 JSON 示例自身必须符合对应 schema，字段组合和示例值应准确、清晰。
- 跨文件路径、definition ID 和外部服务地址可以是说明性 placeholder，不要求在仓库内存在对应 artifact。
- 用于 README 初始化流程的全局配置与 workspace 配置可以保留完整模板定位。
- 新增、删除或重命名示例时，应同步检查生产文档中的示例清单和链接。
