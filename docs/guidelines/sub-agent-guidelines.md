# Sub-agent Guidelines

- sub-agent 适合独立、可并行的调查、验证或特定范围修改；不要把阻塞主线、高耦合或需要关键判断的任务外包。
- 创建 sub-agent 时：
  * 告知只读 / 可写边界、任务目标、输出要求等信息。
  * 除非用户另有要求，否则无需重复 `AGENTS.md` 中已有的约束，这些内容将自动注入 sub-agent 的上下文。
  * 如果用户在会话中给出了额外的规则或偏好，而这些规则同样适用于子任务，请确保在创建 sub-agent 时一并告知。
  * 默认不 fork 当前线程历史（忽略 `fork_context` 或设置其参数为 `false`）。
  * 不未经用户要求而设定非必要的参数，包括但不限于特定模型、思考深度。
- 若授权 sub-agent 修改文件，必须指定明确且互不重叠的写入范围。
- 对于等待 sub-agent 的工具（如 `wait_agent`），时间最低设定为 20分钟 (1200000ms)，
  如果超时未回复，尝试继续等待或者使用任何可以向用户提问的工具（如 `request_user_input`）
  询问 sub-agent 是否还在线，禁止未经用户允许就提前终止正在工作中的 sub-agent。
