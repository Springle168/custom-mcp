# docs/AGENTS.md

本文件面向维护 `custom-mcp` 项目的 AI Agent，作用范围为 `docs/` 及其子目录。若本文件与用户明确指令冲突，以用户指令优先。

## 文档定位

`docs/` 下的文档是开发文档，读者是项目维护者和参与维护的 AI Agent。文档应服务于理解、维护、排查和扩展代码，不按普通用户手册、产品介绍或营销材料的风格编写。

## 内容依据

文档内容以仓库代码中可验证的实现为准，描述代码具备的能力、约束、入口、数据流和维护方式。

不要补充未从代码或用户指令中确认的能力、计划、背景或结论。若代码与文档不一致，应以代码中可验证的实现为准修正文档。

## 按需指南

处理 `docs/` 下的任务时，通过直接目录枚举浅层查看 `docs/guidelines/` 的直属文件名。该目录可能包含仅存在于本地工作区的指南，不要以 Git 已跟踪文件作为完整清单。

根据任务目标和文件名，只读取与任务相关的指南。不要预先批量读取全部指南，也不要递归搜索该目录。

## 资料发现边界

不要仅为补充上下文而关闭 ignore 或其他文件过滤规则，也不要主动递归搜索被排除的文档。
